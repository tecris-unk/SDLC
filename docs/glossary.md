# Глоссарий проекта «TourGuide»

| Термин | Английский эквивалент | Определение в контексте системы «TourGuide» |
| :--- | :--- | :--- |
| Достопримечательность | Landmark / Place | Объект культурного, исторического, природного или гастрономического интереса с географическими координатами, описанием, рейтингом и временем осмотра. |
| Экскурсионный маршрут | Excursion Route | Упорядоченная последовательность точек посещения с рассчитанной геометрией пешеходного пути, общей протяжённостью и суммарной длительностью экскурсии. |
| Точка маршрута | Waypoint / Route Node | Отдельная достопримечательность, включённая пользователем в состав маршрута с указанием порядкового номера обхода. |
| Оптимизация маршрута | Route Optimization | Алгоритмический пересчёт порядка обхода выбранных точек (метод ближайшего соседа с учётом координат) для минимизации времени переходов. |
| АИ-агент рекомендаций | AI Recommendation Agent | Интеллектуальный модуль (`REQ-FUNC-007`), формирующий персонализированный маршрут по текстовому запросу пользователя через LLM API. |
| Картографический провайдер | Map Provider | Внешний геоинформационный сервис (OpenStreetMap + Leaflet / OSRM), обеспечивающий рендеринг тайлов карты и построение полилинии пути. |
| Избранное | Favorites | Персональная коллекция сохранённых достопримечательностей и готовых маршрутов в личном кабинете авторизованного пользователя. |
| JWT-токен | JSON Web Token | Криптографически подписанный токен доступа в ASP.NET Core Identity, используемый для stateless-аутентификации запросов клиента React. |
